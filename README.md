# Kaviyarasu J Portfolio

Modern 3D portfolio built with React, Vite, Three.js, React Three Fiber, Drei, GSAP, Lenis, TailwindCSS, and EmailJS.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Production Build

```bash
npm run build
```

## Contact Form

Create a `.env` file using `.env.example`, then add your EmailJS service ID, template ID, and public key.
